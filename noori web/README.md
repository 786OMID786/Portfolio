# NOORI WEB sample site

Open `index.html` in a browser or serve this folder from any static host. The hero video is expected at `back.mp4` next to `index.html` (`noori web/back.mp4`). Until that file is added, the animated dark gradient background remains visible.

The project cards are clearly labeled concept studies; the card filters, project detail dialogs, mobile navigation, and scroll reveals work without a framework or build step.
